# COPILOT AGENT EXECUTION GUIDE

## Venturam Project Details Page — Pixel Perfect Implementation Mode

---

## 🔴 EXECUTION MODE

You are NOT designing a webpage.

You are converting reference screenshots into HTML, CSS, and JS by matching visual layout geometry.

This task is **pixel-accurate replication**, not design or improvement.

---

## 🔴 GLOBAL RULES (MANDATORY)

1. Implement ONLY the requested section.
2. Do NOT implement future sections unless explicitly instructed.
3. Do NOT modify previously approved sections.
4. Do NOT refactor existing HTML or CSS.
5. Do NOT normalize spacing or typography.
6. Do NOT improve layout or alignment.
7. Screenshot is the layout blueprint.
8. Visual accuracy has priority over code optimization.

---

## 🔴 FILE STRUCTURE (FIXED)

```
/ (root)
    project-details.html

/css/
    project-details.css

/js/
    project-details.js

/project-detail-page/
    (all assets and reference screenshots)
```

Rules:

* project-details.html remains in root.
* CSS must be appended only to project-details.css.
* JS must be appended only to project-details.js.
* All images must load from /project-detail-page/.

---

## 🔴 SECTION EXECUTION RULE

You must work section-by-section.

Process:

1. Implement only the requested section.
2. Match spacing and proportions visually to screenshot.
3. Stop after implementation.
4. Wait for next instruction.

Do NOT continue automatically.

---

## 🔴 LOCK RULE

When instructed that a section is approved:

* Treat its HTML and CSS as frozen.
* Do not modify it further.
* New sections must adapt to existing spacing.

---

## 🔴 OVERLAP RULE

If a section overlaps visually into another section:

* This is intentional.
* Use negative margins or absolute positioning if required.
* Do not separate overlapping sections.

---

## 🔴 RESPONSIVE RULE

Desktop layout is primary reference.

Mobile behavior only when specified:

* Tabs become accordion
* Vertical tabs become accordion

Do not redesign mobile layout.

---

## 🔴 ALLOWED INTERACTIONS ONLY

Allowed:

* counter animation
* tab switching
* accordion expand/collapse
* slider movement
* lightbox open/close

No additional animations allowed.
